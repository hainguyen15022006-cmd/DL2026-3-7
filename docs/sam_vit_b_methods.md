# SAM ViT-B: Methods and Reproducibility

## Report-ready Methods section

We used the pretrained ViT-B variant of the Segment Anything Model (SAM) as the main model [1, 2]. SAM combines an image encoder, a prompt encoder and a mask decoder to produce a segmentation conditioned on spatial prompts. We instantiated the official implementation with `model_type='vit_b'` and the checkpoint `sam_vit_b_01ec64.pth`. No training or fine-tuning was performed in this study; the instructor's interpretation of the training-code requirement remains to be confirmed.

The experiment used the team's fixed COCO val2017 manifest containing 50 image-instance pairs. Original-resolution images were loaded as RGB uint8 arrays. We reused the shared prompts generated by the prompt/runner component with seed 2026. Clean inputs consisted of one positive point or a tight box derived from the ground-truth mask. Shifted prompts used noise levels 0.1 and 0.2, with three trials per level and prompt type. All coordinates referred to the original image. Ground truth was used for prompt construction and evaluation, never for choosing among predicted masks.

The adapter set the model to evaluation mode and performed inference under `torch.inference_mode()`. For each image, `set_image()` computed the image representation once, followed by `predict()` for its prompts. We set `multimask_output=False` and retained one Boolean mask per prompt at the original H x W resolution. The predicted quality score was logged separately from the measured instance IoU. The `seconds` field timed the prompt-specific `predict()` call; image encoding was recorded separately in `encode_seconds`. Encoding time is repeated in each CSV row for an image and must not be summed across its prompts as independent encoding work.

Execution used Python 3.11.9, PyTorch 2.6.0+cpu and four CPU threads on Windows. Although the machine has an NVIDIA MX330 with 2 GB VRAM, these results were obtained on CPU. The first ten manifest entries were used for smoke testing; the completed run resumed those results and covered all 50 entries. It produced 100 clean predictions, shared by Setups 1 and 2, and 600 shifted predictions for Setup 3. All 700 CSV rows reported success. An independent artifact audit checked the delivered masks and recomputed all 700 IoU values against GT, with zero difference from the stored values. This audit did not rerun neural-network inference. These execution checks establish result integrity, not high segmentation accuracy or a speed advantage over MobileSAM.
